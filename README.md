# AMU Studio v0.1.0-beta.4.1（β）

AMU Studio は、SAKU で作ったキャラクターに仕事と記憶を与え、外部の AI を使って動かす Windows のアプリです。

- 1 体のキャラクターが窓口になり、依頼を受けて答えます。
- 判断が要る依頼は、キャラクターの中の席 2〜7 が意見を出し合ってから答えます（1+7）。
- 人（8 席）の同意が要るものは、同意があるまで答えません。

このリポジトリは**配布専用**です。アプリのソースは含みません。

## β版について

- この版はβ（Pre-release）で、v0.1.0-beta.4 の小さな直しの版です。8 席（人）が使う「AMU 8 席コンソール」（デモ版）も、同じ版の番号で添えています。
- **8 席のところは、β.4 と同じくデモです。** 画面に DEMO と出ます。本番の 8 席認証にはつながりません。
- インストーラーには**コード署名**（署名者 wi-t.com Inc.）があります。署名があっても、評判が積み上がるまで Windows SmartScreen が警告を出すことがあります。
- 実行する前に、インストーラーの SHA-256 が、下の値と一致することを確かめてください。
- **AI の答えは「下書き」です。** 承認・決裁・本番の記録にはなりません。
- AMU Studio の設定の画面に、「Owner のリリース記録」「Owner の判断待ち」など、使う人向けに直していない言い方が残っています。

## インストールして使う

1. このリポジトリの [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) から、`AMU Studio_0.1.0-beta.4.1_x64-ai-live-setup.exe` を取得します。
2. SHA-256 が `6fa845481c5c358b60b8a264f3c2957878146f13cb96b3132bafd7d429546b0d`（26,319,112 バイト）と一致することを確かめます。
   `Get-FileHash ".\AMU Studio_0.1.0-beta.4.1_x64-ai-live-setup.exe" -Algorithm SHA256`
3. インストールして起動します。インストールはユーザーごとで、管理者の権限は要りません。SmartScreen の警告が出たら「詳細情報」→「実行」の順に押します。
4. AI の提供元（Anthropic または OpenAI）の API キーは、ご自分のものを使います。キーは、この PC の資格情報マネージャーに保存されます。

**AI の利用料は、API キーの持ち主に、AI の提供元から請求されます。** アプリには、提供元が公開している料金の目安を表示します。

### 初めて起動するとき

- 初めて起動したときは、アプリがしばらく「応答なし」になることがあります。そのときは、アプリを閉じずにお待ちください。
- β.3.1 では、8 席コンソールの初めての起動のときに、PC 全体が 2 分ほど動かなくなったことがありました。β.4 の試験では起きず、8 席コンソールは約 4 秒で起動しました。
- 2 回目からは速く起動します。

## AMU 8 席コンソール（デモ版）

- 8 席（人）が依頼に答えるための、AMU Studio とは別のアプリです。外部の AI には接続しません。
- [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) の `AMU Seat8 Console_0.1.0-beta.4.1_x64-setup.exe`（26,314,752 バイト、SHA-256 `17616848a6eac8912c61998bd7f96fcbec744af0c8e611db7be1cfb847a2207c`）を、AMU Studio とは別に入れます。
- AMU Studio と 8 席コンソールは、同じ共有フォルダーをパスで指してやり取りします。Google ドライブ（パソコン版）の同期フォルダーも使えます（AMU は Google と直接は通信しません）。8 席の回答の本文は、封緘して置きます。
- **デモ版です。** 発行者・8 席認証は本番のものではなく、画面に DEMO と出ます。
- 承認・助言・照会・連絡に答えられます。ただし、デモ版では承認と助言は満たされません（使えるのは確認・照会・連絡です）。
- 2 台の PC での往復は、まだ確かめていません。

## このリリースの変更点

- **設定の画面の古い表示（「β は未署名・未公開」）を直しました。** 配布区分は「β（Pre-release）」で、インストーラーに wi-t.com Inc. のコード署名があることを示します。自動更新は、引き続きありません（新しい版は手動で入れ直します）。
- **編集の画面の「Runtime から戻った候補」で、信頼の一覧の期限と、受け取りの鍵が替わったかを知らせるようにしました。** 期限まで 30 日を切ったとき、期限が切れたとき、鍵が前の一覧と違うときは、書き出し直すよう知らせます。
- そのほかの機能は v0.1.0-beta.4 と同じです。8 席コンソールは、版の番号のほかは β.4 と同じです。
- v0.1.0-beta.3・v0.1.0-beta.3.1・v0.1.0-beta.4 は、公開のまま残します。

詳しくは、[Releases](https://github.com/wi-tcom/KOKOROAMU/releases) のリリースノートをご覧ください。
