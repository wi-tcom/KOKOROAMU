# AMU Studio v0.1.0-beta.4（β）

AMU Studio は、SAKU で作ったキャラクターに仕事と記憶を与え、外部の AI を使って動かす Windows のアプリです。

- 1 体のキャラクターが窓口になり、依頼を受けて答えます。
- 判断が要る依頼は、キャラクターの中の席 2〜7 が意見を出し合ってから答えます（1+7）。
- 人（8 席）の同意が要るものは、同意があるまで答えません。

このリポジトリは**配布専用**です。アプリのソースは含みません。

## β版について

- この版はβ（Pre-release）です。8 席（人）が使う「AMU 8 席コンソール」（デモ版）も、新しい版を添えています。
- **8 席のところは、β.3.1 と同じくデモです。** 画面に DEMO と出ます。本番の 8 席認証にはつながりません。
- インストーラーには**コード署名**（署名者 wi-t.com Inc.）があります。署名があっても、評判が積み上がるまで Windows SmartScreen が警告を出すことがあります。
- 実行する前に、インストーラーの SHA-256 が、下の値と一致することを確かめてください。
- **AI の答えは「下書き」です。** 承認・決裁・本番の記録にはなりません。
- AMU Studio の設定の画面に、署名を付ける前の古い表示（「β は未署名・未公開」など）が残っています。次の版で直します。

## インストールして使う

1. このリポジトリの [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) から、`AMU Studio_0.1.0-beta.4_x64-ai-live-setup.exe` を取得します。
2. SHA-256 が `7eb8161d8c0b0801013cdace7734a39fd38e6f02bccec827721787c64e570b04`（26,327,552 バイト）と一致することを確かめます。
   `Get-FileHash ".\AMU Studio_0.1.0-beta.4_x64-ai-live-setup.exe" -Algorithm SHA256`
3. インストールして起動します。インストールはユーザーごとで、管理者の権限は要りません。SmartScreen の警告が出たら「詳細情報」→「実行」の順に押します。
4. AI の提供元（Anthropic または OpenAI）の API キーは、ご自分のものを使います。キーは、この PC の資格情報マネージャーに保存されます。

**AI の利用料は、API キーの持ち主に、AI の提供元から請求されます。** アプリには、提供元が公開している料金の目安を表示します。

### 初めて起動するとき

- 初めて起動したときは、アプリがしばらく「応答なし」になることがあります。そのときは、アプリを閉じずにお待ちください。
- β.3.1 では、8 席コンソールの初めての起動のときに、PC 全体が 2 分ほど動かなくなったことがありました。β.4 の試験では起きず、8 席コンソールは約 4 秒で起動しました。
- 2 回目からは速く起動します。

## AMU 8 席コンソール（デモ版）

- 8 席（人）が依頼に答えるための、AMU Studio とは別のアプリです。外部の AI には接続しません。
- [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) の `AMU Seat8 Console_0.1.0-beta.4_x64-setup.exe`（26,304,624 バイト、SHA-256 `93b5967e3f8b1b795e8d48335b4d7b8170f94609ccedadd7c9b93c60b22009a0`）を、AMU Studio とは別に入れます。
- AMU Studio と 8 席コンソールは、同じ共有フォルダーをパスで指してやり取りします。Google ドライブ（パソコン版）の同期フォルダーも使えます（AMU は Google と直接は通信しません）。8 席の回答の本文は、封緘して置きます。
- **デモ版です。** 発行者・8 席認証は本番のものではなく、画面に DEMO と出ます。
- 承認・助言・照会・連絡に答えられます。ただし、デモ版では承認と助言は満たされません（使えるのは確認・照会・連絡です）。
- 2 台の PC での往復は、まだ確かめていません。

## このリリースの変更点

- **編集の画面に「Runtime から戻った候補」の欄を加えました。** Runtime が書き出した候補（`.amureturn`）を読み込み、候補ごとに受け入れるかどうかを決めて、署名した受け取り（receipt）を保存します。受け入れても、キャラクターの原本は自動では変わりません。Runtime は、このリリースには含まれていません。
- **8 席の人が加わる会話の前に、依頼する人の国・地域を申告していただくようにしました。** 日本以外か、申告がないときは、8 席の人は加わりません。
- **8 席（人）への依頼の種類が増えました**（承認・助言・照会・連絡）。デモ版では、承認と助言は満たされません。
- **答えの言語を選べるようにしました。**
- 自作のキャラクターを、自分用の署名で、依頼カード（チーム）で動かせるようにしました。
- ウイルス対策ソフトが HTTPS の通信を検査する PC で、AI への送信が失敗することがある件の対策をしました。
- そのほかの直し（席の名前・合議の文・同意の記録の保管など）と、8 席コンソールの変更は、リリースノートに書いています。
- v0.1.0-beta.3 と v0.1.0-beta.3.1 は、公開のまま残します。

詳しくは、[Releases](https://github.com/wi-tcom/KOKOROAMU/releases) のリリースノートをご覧ください。
