# AMU Studio v0.1.0-beta.3（β）

AMU Studio は、SAKU で作ったキャラクターに仕事と記憶を与え、外部の AI を使って動かす Windows のアプリです。

- 1 体のキャラクターが窓口になり、依頼を受けて答えます。
- 判断が要る依頼は、キャラクターの中の席 2〜7 が意見を出し合ってから答えます（1+7）。
- 人（8 席）の同意が要るものは、同意があるまで答えません。

このリポジトリは**配布専用**です。アプリのソースは含みません。

## β版について

- この版はβ（Pre-release）です。
- **コード署名がまだありません。** Windows の SmartScreen やウイルス対策ソフトが、警告を出したり、実行を止めたりすることがあります。
- 実行する前に、インストーラーの SHA-256 が、下の値と一致することを確かめてください。
- **AI の答えは「下書き」です。** 承認・決裁・本番の記録にはなりません。

## インストールして使う

1. このリポジトリの [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) から、`AMU Studio_0.1.0-beta.3_x64-ai-live-setup.exe` を取得します。
2. SHA-256 が `77598d3d4a918d9f5c8067fa0613a31ccdb14f8eb14f0676a821ea911c32ddc6`（26,089,507 バイト）と一致することを確かめます。
   `Get-FileHash ".\AMU Studio_0.1.0-beta.3_x64-ai-live-setup.exe" -Algorithm SHA256`
3. インストールして起動します。インストールはユーザーごとで、管理者の権限は要りません。動く環境は Windows 10／11（x64）です。WebView2 Runtime が無い PC では、インストーラーがインターネットから取得して入れます。SmartScreen の警告が出たら「詳細情報」→「実行」の順に押します。
4. AI の提供元（Anthropic または OpenAI）の API キーは、ご自分のものを使います。キーは、この PC の資格情報マネージャーに保存されます。

**AI の利用料は、API キーの持ち主に、AI の提供元から請求されます。** アプリには、提供元が公開している料金の目安を表示します。

## このリリースの変更点

- **速い合議を加えました。** 判断が要る依頼を、少ない送信で確かめます。6 つの席の意見を 1 回でまとめて聞き、同意しない席などだけを個別に確かめます。
- **合議のしかたを選べるようにしました。** 速い合議（既定）／6 席の合議・早く終える／6 席の合議・3 巡回す、の 3 つです。6 席の合議ほど送信が多く、費用が大きくなります。
- **「アンバーとして合議にかける」ボタンを加えました。** 1 席の分類がアンバーより軽いときはアンバーに上げて合議にかけ、合議で意見がそろっても、8 席（人）の同意があるまで答えません。
- **モデルを、使い始める前に一覧から選ぶようにしました。** 各モデルに、提供元の料金表をもとにした単価の目安が付きます。
- **「考える量」を選べるようにしました。** 提供元に任せる（既定）／少なく／考えない、の 3 つです。考える量を減らしたときの答えへの影響は、まだ確かめていません。
- **キャラクターの文の使い回し（キャッシュ）で、費用を下げるようにしました。**
- **ERABAZU の職能テンプレートの署名を、公開されている鍵の一覧で確かめるようにしました。**
- **SAKU で作った自作の Character の ZIP を取り込めるようにしました。** 署名が無いため「自作・未確認」の印が付きます。この版では、取り込んで一覧に登録するところまでで、自作の Character をチームに入れて動かすことはまだできません。
- **サンプル Character 3 体（サンプルモード）を同梱しました。** キャラクター選択の「サンプルを読み込む」から選べます（権利条件は、サンプルのパックに同梱の LICENSE.md〔`LicenseRef-WIT-Sample-1.0`〕によります。OSS ではありません）。

詳しくは、[Releases](https://github.com/wi-tcom/KOKOROAMU/releases) のリリースノートをご覧ください。
