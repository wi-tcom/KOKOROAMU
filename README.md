# KOKOROAMU：AMU Studio v0.1.0-beta.5（β）・MACHI Guild v0.4.0-beta.1（β）

AMU Studio は、SAKU で作ったキャラクターに仕事と記憶を与え、外部の AI を使って動かす Windows のアプリです。

- 1 体のキャラクターが窓口になり、依頼を受けて答えます。
- 判断が要る依頼は、キャラクターの中の席 2〜7 が意見を出し合ってから答えます（1+7）。
- 大事なところは、人（8 席）が確かめてから進みます。

MACHI Guild（β）は、下の「MACHI Guild（β）」の節をご覧ください。

このリポジトリは**配布専用**です。アプリのソースは含みません。

## β版について

- この版はβ（Pre-release）です。8 席（人）が答える「AMU 8 席コンソール」と、商品のプログラムに組み込む「AMU Runtime」の zip も、同じ版で添えています。
- インストーラーには**コード署名**（署名者 wi-t.com Inc.）があります。署名があっても、評判が積み上がるまで Windows SmartScreen が警告を出すことがあります。
- 実行する前に、インストーラーの SHA-256 が、下の値と一致することを確かめてください。
- **AI の答えは「下書き」です。** 承認・決裁・本番の記録にはなりません。
- **PC が乗っ取られた場合の守りは、この製品の保証の外です。** 管理者の権限で PC を完全に操られた場合、送信の記録や鍵の守りは働かないことがあります。

## インストールして使う

1. このリポジトリの [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) から、`AMU.Studio_0.1.0-beta.5_x64-ai-live-setup.exe` を取得します。
2. SHA-256 が `782ad233be06ced8b9ed130b3d3e9d5e355ead28a1de03bf5d28c50a4865b7af`（94,702,896 バイト）と一致することを確かめます。
   `Get-FileHash ".\AMU.Studio_0.1.0-beta.5_x64-ai-live-setup.exe" -Algorithm SHA256`
3. インストールして起動します。インストールはユーザーごとで、管理者の権限は要りません。SmartScreen の警告が出たら「詳細情報」→「実行」の順に押します。v0.1.0-beta.4.1 の上に、上書きでインストールできます。
4. AI の提供元（Anthropic・OpenAI・Gemini）の API キーは、ご自分のものを使います。キーは、この PC の資格情報マネージャーに保存されます。この PC の Ollama で動かすこともできます。

**AI の利用料は、API キーの持ち主に、AI の提供元から請求されます。** アプリには、提供元が公開している料金の目安を表示します。

ここに書いたファイル名は、GitHub から落ちてくる名前です（名前の空白は「.」に替わっています）。

### 初めて起動するとき

- 初めて起動したときは、アプリがしばらく「応答なし」になることがあります。そのときは、アプリを閉じずにお待ちください。
- 2 回目からは速く起動します。

## AMU 8 席コンソール

- 8 席（人）が依頼に答えるための、AMU Studio とは別のアプリです。AMU Studio と同じ PC にも入れられます。
- [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) の `AMU.Seat8.Console_0.1.0-beta.5_x64-ai-live-setup.exe`（27,045,096 バイト、SHA-256 `06758bd12b6a3d7f79f82c76e1da21752ace71a61f06846c751446a7a3d19985`）を入れます。
- AMU Studio と 8 席コンソールは、同じ共有フォルダーを見て、合言葉で鍵を交換してから、依頼と答えをやり取りします。合言葉はファイルに書かず、起動のたびに入れます。合言葉の試みが 5 回通らないと止まります。
- 8 席コンソールの答え（「確認した（進めてよい）」など）は、コンソールの鍵で署名して返します。**署名の確かめが示すのは、記録された答えと公開鍵の署名が技術的に合っていることまでです。** 答えた人・その人の意思・本人性・資格・組織上の権限・実際の答えの時刻を証明するものではありません。当社は、答える人の本人確認・資格の確認・権限の確認を行いません（AI製品・サービス利用特約 第07条）。
- 8 席に頼めるのは「確認」です。承認と助言は、この版ではありません。
- **AI の下書きは、試験中の機能です。** 2 段の 8 席（受ける側のコンソールが 2 つ）の通しは、まだ確かめていません。下書きが出ないときは、8 席の人が答える道で進めてください（人の答え・鍵の交換・会話は、下書きが無くても使えます）。

## AMU Runtime の zip（商品のプログラムに組み込む）

- [Releases](https://github.com/wi-tcom/KOKOROAMU/releases) の `AMU_RUNTIME_0.1.0-d38b051_win-x64.zip`（40,616,774 バイト、SHA-256 `552e7f861febf391e92187383e036508289a94a5217cab1fb1ab36195b8e670d`）。AMU Studio のインストーラーにも入っています。
- インストーラーはありません。使う前に、Runtime を動かす Windows の利用者で（管理者や SYSTEM ではなく）、次のコマンドを 1 回実行します。
  `amu-runtime-host.exe --init-ai-ledger --data-dir <Runtime のデータの場所>`
- zip そのものにはコード署名はありません（zip の形には付けられないため）。展開した中の実行ファイルには、コード署名があります。

## このリリースの変更点

- **AI への送信を、落ちても失われない記録に残すようにしました。** 送っている途中でアプリや PC が止まり、届いたかどうか分からなくなった送信は、二重に送らないよう、自動では送り直しません。次に起動したとき、画面の上に件数を出し、一覧から確かめた結果を記録できます（記録するだけで、送り直しはしません）。送信の記録が使えないときは、何も送りません。
- **8 席コンソールと、共有フォルダーと合言葉でつなぐようにしました。**
- **書き出しを増やしました。** 8 席コンソール一式（.amupkg と .amuseat8pkg を一度に）・8 席コンソールのパッケージ・記憶の束を保存できます。保存先は、この PC の「ダウンロード」フォルダーです。一覧の署名の印を SAKU Builder と同じ言葉にし、パックを編集したキャラクターを書き出すときは、元のパックの使用条件が続くことを確かめてから書き出します。
- **Gemini を選んだときの知らせを足しました。** 学習への利用を禁じた Character Pack のキャラクターなどでは、Gemini を選べません。
- **「送る前の確認」を整えました。** 「送らない」を選んだときは、送りません。
- v0.1.0-beta.3・v0.1.0-beta.3.1・v0.1.0-beta.4・v0.1.0-beta.4.1 は、公開のまま残します。

詳しくは、[Releases](https://github.com/wi-tcom/KOKOROAMU/releases) のリリースノートをご覧ください。

## 既知の制限

- 8 席コンソールの AI の下書きは、試験中の機能です（上の「AMU 8 席コンソール」の項）。
- Runtime から戻った候補を受け入れても、新しい Runtime Package は作られません。
- 書き出しやバックアップの保存先は選べません（この PC の「ダウンロード」フォルダーに保存します）。
- AMU Studio を 2 つ開くと、2 つ目の窓は読み取り専用になり、送信もしません（仕様です）。
- Windows x64 のみ。画面は日本語だけです（答えの言語は選べます）。
